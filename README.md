# Enterprise Core — бета-канал

Здесь публикуются бета-сборки Android-приложения Enterprise Core. Бета ставится рядом с релизом: отдельный пакет, данные релиза не затрагиваются.

## Что нового в бете по сравнению с релизом 1.7.56

Бета собрана на основе релиза 1.7.56. Ниже — всё, чем она отличается от релиза.

**1. Antigravity: модель Google**

- Вход через аккаунт Google.
- Доступна одна модель — та, которую предоставляет ваш аккаунт.
- Изображения, документы и аудио уходят в модель как вложения, без ручного копирования текста.
- Если аккаунт отдаёт рассуждения модели, они показываются в ответе.
- Если Google ограничил аккаунт, приложение объясняет причину по-русски и даёт ссылку на обращение в поддержку.

**2. Новые провайдеры**

- iFlow: вход по коду в браузере, ключ подхватывается автоматически.
- Qwen Code: вход по коду устройства, без ручного переноса токенов.

**3. Бесплатный канал**

- Бесплатный канал доработан: ответы приходят стабильнее.
- У бесплатных моделей действуют суточные лимиты — когда они исчерпаны, приложение предложит попробовать позже.

**4. Доступ к провайдерам**

- Настройка провайдеров сосредоточена на Enterprise Core API и понятном описании, что вы получаете.
- Дополнительные каналы открываются по балансу аккаунта.
- Есть скрытый доступ по коду — для тех, кому он нужен.

**5. Локальный шлюз**

- Приложение может отдавать свои модели в локальную сеть по адресу, совместимому с OpenAI: список моделей и чат с потоковым ответом.
- Включается в настройках провайдеров, доступ закрыт ключом, который вы задаёте сами.

**6. Оформление**

- Основной темой стала Enterprise Diamond.
- Перелив на стекле реагирует на наклон телефона.
- Меню, карточки и панели выделения текста оформлены одним стеклянным материалом.
- Шапка чата стала выше, верхняя кромка без блика у строки состояния.
- Окно «Компьютер» получило скруглённые углы.
- Тактильный отклик срабатывает только при нажатии: прокрутка и случайное касание не вибрируют.

**7. Список чатов**

- Между беседами появился отступ, список больше не выглядит одной плотной лентой.
- Кнопки создания чата и поиска приведены к единому виду.

**8. Обновления**

- В релизном приложении появилась кнопка «Обновить бету»: она проверяет этот репозиторий, скачивает новую сборку и ставит её рядом с релизом.
- Перед установкой проверяется целостность файла; если разрешение на установку не выдано, приложение открывает нужный экран и после возврата продолжает без повторного скачивания.

**9. Исправления**

- Исправлено: на экране приветствия и на странице использования текст читается на тёмной теме.
- Исправлено: VPN-сервис мог не успеть запуститься в фоне при включении VPN.
- Исправлено: окно «Компьютер» выходило за скругления экрана.
- Исправлено: меню и подсказки в чате просвечивали текстом из-под них.

**Оптимизация приложения и повышение стабильности.**

Установка: скачайте APK ниже. Бета ставится рядом с релизом, данные релиза не затрагиваются.

## Как установить

1. Откройте последнюю сборку в разделе Releases.
2. Скачайте APK для arm64-v8a.
3. Подтвердите установку. Если система попросит разрешение «установка из неизвестных источников», разрешите для приложения, из которого открываете файл.

В релизном приложении обновления беты можно ставить кнопкой «Обновить бету» в настройках проверки обновлений.
